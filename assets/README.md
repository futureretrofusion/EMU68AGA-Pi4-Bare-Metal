# Original splash artwork, pixel-exact source

EMU68AGA_Bare_Metal_Splash.png is a LOSSLESS reconstruction of the
480x270 rendered RGB565 image embedded in
machine/Emu68/include/logo/logo_aga_rgb.h. It has the exact same
RGB565 pixel values as the boot splash and is supplied in a common
editable image format. The higher-resolution/artist's original
file, if any, was not found in this source snapshot.

R101 does NOT modify this picture. Its POST box is drawn separately
at runtime on the Pi4 firmware framebuffer during startup.
